# Show Hit List

**A private, one-page list of graded Pokémon cards worth looking for at a card show.**

Collectible card prices are tracked by sites like Card Ladder, which record what each card has recently sold for. Sometimes a card is up for auction online (on Alt, Fanatics, Goldin or eBay) and the bidding is already higher than its recent sales. That card's recorded value will likely go up once the auction ends. This page lists those cards, so its owner can try to buy one at a card show at today's price before that happens. The page is rebuilt from data gathered separately; the gathering itself isn't part of this repo.

## What you can do with it

- See which cards currently have a live auction priced above their recent sales.
- Switch between "Solid" picks (cards that pass every safety check) and all cards, each with the reason it isn't solid.
- Filter by auction site and by how much you're willing to spend.
- See, for each card, the most you should pay and an estimated profit, with fees on both sides included.
- Check the card's recent sales, with odd outliers crossed out so they don't skew the price.

This is a personal tool, not financial advice. The profit numbers are estimates based on stated assumptions.
